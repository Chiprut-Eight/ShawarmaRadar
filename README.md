# 🥙 ShawarmaRadar — מכ"ם השווארמה של ישראל

> **מסמך שורש הפרויקט (Single Source of Truth)**  
> מסמך זה מגדיר במדויק את מהות הפרויקט, הארכיטקטורה החינמית שלו, אלגוריתם הדירוג ומבנה המערכת.

## 🎯 1. מהות הפרויקט והחזון

**ShawarmaRadar (מכ"ם השווארמה)** הוא מערכת אוטונומית לאיסוף נתונים, עיבוד שפה טבעית (NLP בעברית) ודירוג שקוף של שווארמיות בישראל.  
המערכת אוספת נתונים פומביים ממספר מקורות, מזקקת אותם לציון משוקלל אחד (`0%` עד `100%`), ומציגה:
1. **מלך השווארמה הארצי** — השווארמיה המובילה בישראל ברגע זה.
2. **מלכי האזורים (5 אזורים)** — הדירוג המוביל ב**צפון**, **מרכז**, **שרון**, **שפלה** ו**דרום**.
3. **דו"ח מודיעין יומי לטלגרם** — עדכון אוטומטי הנשלח בסיום הסריקה היומית.

### עקרונות הברזל של הפרויקט
* **100% חינמי לתמיד (Zero-Cost Architecture / 0 ₪ עלות)**:
  * ללא שרתים בתשלום (ללא Render וללא שרתי VPS).
  * ללא מנויי API בתשלום שוטף (ללא חיובי OpenAI או Apify).
  * אירוח חינמי ב-**Firebase Hosting** ואוטומציה חינמית ב-**GitHub Actions**.
* **שווארמיות בלבד**:
  * המכ"ם מציג אך ורק עסקים שמוכרים שווארמה כמרכיב מרכזי (ללא מאפיות/טאבון בלבד, פיצריות, המבורגריות, סושי או מסעדות שאינן שווארמיות).
* **דיוק גיאוגרפי וכתובות מלאות**:
  * כל עסק חייב להיות משויך לעיר הנכונה שלו ולהציג את הכתובת המדויקת (רחוב ומספר בית) כפי שהיא מופיעה בגוגל.

## 🏗️ 2. ארכיטקטורת המערכת (Serverless & 100% Free)

המערכת בנויה בארכיטקטורת **Static Bundle + Scheduled GitHub Action** שמבטיחה טעינה מיידית (`0ms` השהיית שרת) ואפס עלויות תשתית:

```
[GitHub Actions Cron (יומי)]
       │
       ▼
[backend/worker.py] ──► סריקת מקורות (Google / Wolt / 10Bis) + NLP עברי מקומי
       │
       ▼
[backend/shawarma_radar.db] ──► עדכון מסד הנתונים המקומי (SQLite הנשמר בגיט)
       │
       ├──► שליחת דו"ח יומי לבוט הטלגרם (Telegram Bot API)
       │
       ▼
[backend/export_json.py] ──► ייצוא ל-frontend/src/data/restaurants_data.json
       │
       ▼
[Vite Build & Firebase Deploy] ──► פריסה אוטומטית ל-https://shawarmaradar-app.web.app
```

### רכיבי התשתית
1. **Frontend (`frontend/`)**:
   * בנוי ב-**React 19 + TypeScript + Vite**.
   * ממשק משתמש בסגנון מכ"ם טקטי, מותאם למובייל (PWA) ודו-לשוני מלא (עברית `RTL` / אנגלית `LTR` באמצעות `i18next`).
   * טוען את הנתונים מיידית מתוך `frontend/src/data/restaurants_data.json` (עם תמיכה בשליפה מ-Firebase Firestore דרך `frontend/src/services/firebase.ts`).
2. **Hosting (`firebase.json`, `.firebaserc`)**:
   * מתארח ב-**Google Firebase Hosting** תחת הפרויקט `shawarmaradar-app`.
   * כתובת האתר באוויר: `https://shawarmaradar-app.web.app`
3. **Backend & Scraper (`backend/`)**:
   * כתוב ב-**Python 3.11+** עם `SQLAlchemy` ו-`SQLite` (`backend/shawarma_radar.db`).
   * אין צורך בשרת שמאזין 24/7 באוויר: הסריקה רצה כמשימה מתוזמנת, מעדכנת את קובץ ה-SQLite וה-JSON, ופורסת גרסה מעודכנת ל-Firebase.
   * קובץ `backend/main.py` (FastAPI) נשמר עבור הרצה ופיתוח מקומיים בלבד.
4. **אוטומציה (`.github/workflows/daily-scraper.yml`)**:
   * תהליך **GitHub Actions** המריץ את הסריקה, מייצא את ה-JSON, מבצע `git commit & push` למאגר, ופורס ל-Firebase Hosting באמצעות `FIREBASE_SERVICE_ACCOUNT_SHAWARMARADAR_APP`.

## 🧮 3. אלגוריתם הדירוג של המכ"ם (0% – 100%)

הציון הסופי (`bayesian_average`) מחושב בקובץ [`backend/nlp.py`](backend/nlp.py) ומורכב מ-4 שכבות (סה"כ 100 נקודות):

### א. מוניטין גוגל בייסיאני — 40% (עד 40 נקודות)
כדי למנוע ממקום חדש עם 3 ביקורות של 5 כוכבים לעקוף שווארמיה ותיקה עם 1,500 ביקורות וציון 4.7, מחושב **ממוצע בייסיאני** עם רף אמינות של `40` ביקורות וממוצע בסיס של `3.5` כוכבים:
* `דירוג בייסיאני = (כמות ביקורות / (כמות ביקורות + 40)) * ציון גוגל + (40 / (כמות ביקורות + 40)) * 3.5`
* `ניקוד גוגל = (דירוג בייסיאני / 5.0) * 40`

### ב. מדד וולט (Wolt) וביקוש משלוחים — 30% (עד 30 נקודות)
* **אם העסק קיים בוולט**: `ניקוד וולט = (ציון וולט / 10.0) * 30`
* **אם העסק אינו בוולט** (שווארמיות מסורתיות ללא משלוחים): ניתן ציון בסיס הוגן כדי לא לפגוע בהן: `(דירוג בייסיאני / 5.0) * 24`

### ג. מדד תן ביס (10Bis) — 15% (עד 15 נקודות)
* **אם העסק קיים בתן ביס**: `ניקוד תן ביס = (ציון תן ביס / 5.0) * 15`
* **אם העסק אינו בתן ביס**: ניתן ציון בסיס הוגן: `(דירוג בייסיאני / 5.0) * 12`

### ד. סנטימנט חי וסלנג שווארמה עברי — 15% (עד 15 נקודות)
מנוע NLP מקומי וחינמי בפייתון המנתח טקסטים בעברית:
* **מילים חיוביות**: `"אש"`, `"פצצה"`, `"נדיר"`, `"עסיסי"`, `"בשר איכותי"`, `"מפנק"`, `"שירות עשר"`, `"לאפה חמה"`, `"טרי"`.
* **מילים שליליות**: `"יבש"`, `"קמצנים"`, `"קלקול קיבה"`, `"על הפנים"`, `"מגעיל"`, `"בשר לא עשוי"`, `"גומי"`, `"מאכזב"`.
* **זיהוי שלילות**: היפוך ציון כאשר מופיעה מילת שלילה לפני מילת המפתח (`"לא עסיסי"`, `"ממש לא טעים"`).
* **מכפיל טריות (Recency Decay)**: ביקורות מ-24 השעות האחרונות מקבלות משקל של עד פי `3.0x`, עם דעיכה הדרגתית לאורך 180 יום.
* **ציון בסיס ניטרלי**: `7.5` נקודות (עולה עד `15` בסנטימנט חיובי או יורד עד `0` בסנטימנט שלילי).

## 🔐 5. משתני סביבה וסודות (GitHub Secrets)

עבור הרצת האוטומציה ב-GitHub Actions מוגדרים הסודות הבאים במאגר:
* `TELEGRAM_BOT_TOKEN` — טוקן בוט הטלגרם לשליחת הדו"ח היומי.
* `TELEGRAM_CHAT_ID` — מזהה הצ'אט לקבלת ההתראות.
* `FIREBASE_SERVICE_ACCOUNT_SHAWARMARADAR_APP` — מפתח Service Account לפריסה אוטומטית ל-Firebase Hosting.
